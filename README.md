# Leaf Disease Detection using CNN

This project detects plant leaf diseases using a Convolutional Neural Network (CNN).

Technologies Used:
- Python
- TensorFlow / Keras
- Streamlit

Features:
- Upload leaf image
- Detect plant disease
- Display prediction result
